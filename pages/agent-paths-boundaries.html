三团队职责分工边界

按 Agent 研发时序排列：每个阶段谁产出什么、谁提供什么底座、谁维护什么生态。

边界原则

Agent 团队负责“业务做得对不对”
Runtime/Core 负责“能否稳定、透明、可调试地运行”
Ecosystem 负责“能安全、稳定地连接多少外部能力”

阶段 领域 / 归属逻辑 Agent 业务团队 快速交付业务 Agent，含自建 Tool / Skill Wanpix Runtime / Core 定义统一接口与规范，让 Agent 与 Runtime 解耦 Wanpix Ecosystem 生态资产：技能 · 专家 · 连接器 · 知识 · 渠道
01 技术选型 框架与自研 Runtime接口规范收口，实现可替换 提需求、试点和验收；只依赖稳定接口，不绑定具体 Runtime 实现 唯一建设 Owner定义公司统一 Agent Contract 与接口规范（Manifest / 调用协议 / 事件语义 / Tool·Skill·Knowledge 契约），Agent 与 Runtime 解耦，接口稳定即可换实现 按标准契约接入新 Runtime，连接器不绑死框架
新框架选型收口到 Runtime/Core 不 fork 框架，不形成私有 Runtime 选型 Owner候选须过同一组 Loop Conformance / Tool Contract / 事件顺序 / 取消恢复 / Trace 测试 提供跨 Runtime Adapter 与渠道能力兼容矩阵，不兼容项构建期失败
02 应用开发 业务 Agent编排归业务，第三方准入归生态 业务 OwnerPrompt / Skill 编排、多 Agent 编排、业务逻辑与业务 SLO；提交 Manifest 声明 runtime / capabilities / permissions / limits 统一 Agent 调用协议与 SDK 稳定面；第三方 Agent 以外部 Endpoint 注册，纳入同一 Gateway 的身份、权限、限流与 Trace 边界；Manifest 三层校验：Schema → Registry → Policy 专家模板预置专家与可复用 Skill 供派生；第三方 Agent 的引入、准入评估与上架，与技能 / 连接器同一 Hub
Tool / Skill业务自建，生态双向引入与发布 主要开发方自建业务 Tool 与 Skill：业务逻辑、判断规则、示例与 Eval；再选择、组合并反馈效果 定义 Tool / Skill 契约与调用链路；MCP 运行时网关、鉴权、限流和策略执行 Skill & Connector Hub统一 Registry、目录、版本与文档，Skill 与连接器 / MCP Server 同库收录；引入第三方 / 开源 Skill 与 MCP Server 接入适配；发布内部优秀 Skill 输出到第三方平台
03 知识记忆 知识与检索内容归业务，接入归生态，契约归平台 维护业务知识内容与评测集，声明数据分级 定义统一检索契约（Knowledge / Retrieval API）与运行时策略；检索结果进 context.assembled，上下文可解释可对比 知识源接入对接各类知识库（文档库 / Wiki / 对象存储 / 数据库 / 第三方 SaaS），统一为 Runtime 可直接消费的知识接口；管索引生命周期、切片向量化与增量同步
记忆规则归业务，读写归平台 定义“记什么、何时读、何时忘”的业务规则与效果验收 Memory API三层记忆（Run 内 / 跨会话 / 长期）、写入准入与置信度、TTL 与遗忘、租户命名空间；Checkpoint 只存快照版本 + 引用 + 幂等键 向量 / 搜索连接器与嵌入服务适配
04 运行环境 会话与上下文语义归业务，中控归平台 定义会话语义、多轮策略与内容来源；禁止直接拼接不可观测的历史消息 Session / Context APIsessionId 生命周期、会话↔Run 1:N 与并发租约、token 预算 / 截断 / 摘要、断线重连合并；每次模型调用记 context.assembled 知识 / 文档连接器与切片能力
沙箱 · 密钥 · 配额 · 隔离业务配策略，平台给底座 配置业务策略，不自行实现隔离 共享底座Sandbox / Secret / Quota；出站 allowlist 与 SSRF 防护、租户级文件隔离、CPU / 内存 / 时长上限；密钥只走 Secret Manager 沙箱内可用的连接器与依赖白名单
05 发布运维 可观测与调试业务定指标，平台给链路 定义业务指标；提供失败样本定位业务问题 Trace / Replay统一事件模型：run.start / model.call / tool.call / memory.read / context.assembled / approval.wait / error；大字段走对象存储只存引用 Tool / Connector 调用指标与错误归因
发布和运行业务验收，平台托管 业务验收、Eval、Agent 一级响应 Gateway路由键 agentName + environment + version/channel；local → preview → staging → canary → production；灰度含流量比例、租户范围、成功率阈值与自动回滚 渠道适配渠道分发与版本、连接器及第三方依赖 SLO
06 合规治理 数据留存与合规业务提诉求，平台强制基线 声明业务数据分级与留存诉求 强制基线按环境与数据分类定保留周期；字段级脱敏与租户隔离；Replay Fixture 默认脱敏；Trace 不复制记忆库 保证连接器侧数据不越权落盘
成本与配额归因业务担目标，平台给口径 对单个 Agent 的成本目标负责；Eval 带 token 与成本估算 计量与配额计量 token / Tool 次数 / 资源；配额与限流在 Gateway 执行，归因到 Agent / 租户 / 渠道 连接器调用成本口径与第三方配额
