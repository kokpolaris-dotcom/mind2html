01

改造并开放现有 Wanpix

存量 · 原地增强

存量风险 最低 资产复用 最高 自由度 中
保留现有 Wanpix + Mastra Runtime，不发起迁移
开放完整 Trace：模型 · Tool · 状态 · 错误链路
补齐Replay 与本地 / Preview 调试
接入Agent · Skill · Tool 进入 Git / PR / CI·CD
开放版本 · 发布 · 灰度 · 回滚 接口

最适合已经上线、强依赖 Wanpix 的 Agent：在不迁移的前提下提升迭代与排障效率。

02

原生 Mastra 开发 · 团队自托管

增量 · 快速验证

首版速度 高 自由度 高 上线依赖 共享能力
开发Git · IDE · Vibe Coding · 传统 CI·CD
托管团队自托管运行服务，掌握代码与调试过程
接入经统一 Agent Gateway 接入公司门户
复用公司 LLM Gateway · Tool/Skill · 权限 · 观测
前置Gateway · Trace · Sandbox · Checkpoint 就绪

生产上线速度取决于共享能力交付；共享能力就绪前仅适用于低风险、无生产写副作用、不处理敏感数据的 Agent。

03

长期 · 按证据进入
